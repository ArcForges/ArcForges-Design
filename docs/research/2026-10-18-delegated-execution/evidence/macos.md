# macOS mechanisms: evidence record

- **Scope:** research evidence of the 2026-10-18 delegated-execution study; evidence labels E1–E6 as defined in the study; not verification-register facts.
- **Date:** 2026-10-18.
- **Source reports:** the study report 12 (macOS track, including its inline verification markers and 55-row verification log) and the study's macos digest (section 1, mechanism fact sheet).
- **Publication:** curated 2026-10-19 for the public ArcForges-Design repository (`docs/research/2026-10-18-delegated-execution/`). No row describes a particular host.
- **Report section column:** names the section of the study report 12 the fact was drawn from. The study reports and digests are working files of the study and are not published; the primary-source column is the citable evidence.
- **Review corrections:** the study's review round of 2026-10-18 ruled some values in this file overstated or premature. The table at the end names each affected fact, the ruling and the corrected statement. Where a claim and its correction differ, the corrected statement governs. Claim text is left unedited so its provenance stays visible.
- "Analysis, no primary source" marks a claim that rests on the study's own reasoning.
- **Reading notes:** No macOS E1 exists: macOS is outside ArcForges' current validation venues (AD-0002), and nothing was run. Where the report's verification log corrected the original text, the corrected statement and label are used. "VM plan" refers to the experiment plans in the report's section 13; none has run. LAB-… IDs name entries of `lab-register.md` in this folder.

## Review corrections

The corrected statement governs where it differs from the claim above. Rulings named C-nn and N-nn are from the study's consolidated review (2026-10-18), which is not published, so each corrected statement is given in full. Every corrected value is pre-lab until the named lab runs.

| D-macos-7, D-macos-6 | C-42 | Without disclaim the LaunchAgent node is the responsible process, so grants given at prompts raised by one managed tool (Documents, Desktop, Downloads, volumes, camera, microphone, Local Network) are held by ArcForges and apply to every later tool. The node reports `tcc_attribution = NODE (aggregating)` by default and says so on the first screen and in the release scope; such prompts should be declined unless intended. Disclaim is PREFERRED only, and "non-aggregation" is claimed only while disclaim is active and probed (LAB-MAC-02). |

| D-macos-10, D-macos-11 | C-44 | Seatbelt profiles are an exploratory direction of their own (EX-22), not accepted work: the accepted macOS row (RM-15) is the stage-1 monitored node, which uses no Seatbelt. |
