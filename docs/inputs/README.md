# Design Inputs

This directory preserves the original design inputs and exploration records for the ArcForges product family.

These documents provide historical context, rationale, and foundational technical concepts that inform current requirements, architecture, and planning.

These files are preserved inputs, not final authority. They may contain obsolete names, decisions from different points in time, internal contradictions, unvalidated assumptions and outdated external claims. They are never modified. Accepted corrections and decisions live in [`docs/decisions/`](../decisions/); review coverage lives in [`docs/assurance/`](../assurance/).
