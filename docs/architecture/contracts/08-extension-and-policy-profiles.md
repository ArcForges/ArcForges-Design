# Initial Extension and Policy Schemas

Authority: [P2-010](../../decisions/phase-2-specification-decisions.md#rule-p2-010), [extension architecture](../15-extension-platform-architecture.md), [policy requirements](../../requirements/11-policy-and-configuration.md). These closed profiles are implemented as authored schemas in Contracts and generated validators/types in each applicable language. They are not arbitrary JSON or a second business protocol. Public packaging/SDK code and internal schemas are Apache-2.0; internal access restrictions remain.

## 1. Package manifest.v1

An `.arcpkg` is a ZIP with root `manifest.json`, `inventory.json`, `signature.json`, licence/NOTICE and declared files. Reject traversal, absolute/drive/UNC paths, symlinks, case-fold path collision, duplicate ZIP entries and undeclared files. Maximum compressed 256 MiB, expanded 1 GiB,10000files, individual 128 MiB; validate declared size/ratio and limits while streaming, before execution. No install script. Every inventory entry is relative slash path, byte length and SHA256; entries sorted ordinal. Signature Ed25519 signs the canonical manifest hash and inventory hash with publisher/key/version. Revoked/unknown trust is shown and follows existing install policy; developer mode never disables OS isolation/grants.

The [normative inventory.v1 definition](../../assurance/wp03-00-contract-structure-profile.md#canonical-inventoryv1-definition) fixes the closed JSON container and entry properties, canonical decimal size strings, portable ASCII path/collision rules and self-reference exclusions. Payload inventory includes manifest and applicable licence/NOTICE files, excluding root inventory.json/signature.json. Its WP03.00 CLI validation proves document shape and declared bounds only; it does not replace archive-byte, hash, signature or trust verification.

| Field | Type / required behavior |
|---|---|
| schemaVersion | Exact string manifest.v1 |
| packageId/version | Reverse-domain ASCII identifier<=128; SemVer2, immutable package/version/hash |
| publisherId/signingKeyId | Registered publisher/key identity; key bytes in trusted catalog/developer trust store, not asserted by this file |
| name/description | Localized text map of BCP47 to text,1–16 locales, name256 scalars, description 4096; no markup execution |
| platforms | Nonempty list of explicit OS/RID pairs supported by each executable; content-only may use any |
| contractRanges | Exact capability/protocol package ID and admitted major/min/max version; no unbounded wildcard major |
| contributions |1–256 typed contribution records; keys unique in package, never reserved first-party namespace |
| permissions | Declared capability/resource/network/background requirements with reason; no credential or arbitrary OS path in the manifest |
| dependencies |0–64 package ID plus exact compatible version range, no cycle; resolution pinned in installation receipt before activation |
| executables | RID→relative executable path/hash, declared runtime/system dependency IDs, no command-line shell string; executable family only |
| privateState | schemaVersion(uint32), maxBytes(≤256 MiB), migration compatibility range; no executable migration install script |
| resources | inventory paths referenced by typed content, hashes and licence provenance |

Common contribution is `{id,kind,titleKey,descriptionKey?,inputSchemaId?,outputSchemaId?,permissions,body:<kind record>}`. Kind is exactly skill/template/workflow/mcp/connector/extension. Presets and recipes are typed template content; third-party peer Arc App integration is future-only, outside the current host and generation surface; external-agent/ACP planner contributions remain excluded.

| Kind | Exact payload/profile and execution boundary |
|---|---|
| Skill | guidance Markdown path/hash<=256 KiB, trigger labels<=32, context policy keys and referenced capability IDs. Guidance is untrusted instruction content, grants no capability and cannot override system/user rules. |
| Template | ownerProduct, templateKind (notesDocument/chatPrompt/scopeRecipe/slatePreset), typed body resource/schema version, parameters and output capability ID. Materialization is an ordinary owner command with preview/revision/origin, not DB/file mutation. |
| Workflow | workflow.v1 typed DAG below, input/output schema and admitted capability IDs. Compiles into the existing AgentTask plan/steps, no second model loop. |
| MCP | protocolVersion, transport stdio or streamableHttp, command/executable declaration or exact HTTPS server origin, tool allowlist and parameter schema digests, per-call limits. stdio is explicitly broader machine trust, not a falsely sandboxed extension. MCP cannot introduce another autonomous planner. |
| Connector | definitionId, authKind none/oauth2/personalToken, exact configured provider origins/scopes, secret input field descriptions, typed capability binding and egress limits. Connection instance separately owns SecretRef/account/grant/status; package never contains a token. |
| Extension | executable mapping, typed extension points, declarative panels/settings and background permission. One isolated process per active package installation, no in-process assembly/control loading. |

Template parameters use the existing closed scalar model: text/bool/int64/decimal/enum/resourceRef, declared required/default/range/maxLength and≤64 fields. Placeholder interpolation is a token AST literal/parameter, not eval or recursive template expansion; escape for target text/URL/query context declared by templateKind. A resourceRef remains a reference and cannot turn into a local path. Unknown parameter refuses; missing required input never gets a guessed value. Source origin is unioned into created content under the normal origin profile.

## 2. Workflow and declarative UI

`workflow.v1` has inputs, nodes, outputs, limits. Node union: constant(typedValue); input(name); select(recordField from declared schema); capability(operationId,typedArguments,dependencies); condition(predicate,thenNodes,elseNodes); foreach(inputArray,maxItems,body); output(valueRef). Value references are nodeId+declared field, never reflection paths. Predicate is eq/ne/lt/le/gt/ge/exists/all/any on compatible scalars, depth≤8/nodes≤128. ForEach maxItems≤100 and nesting≤2; total expanded execution≤256 steps before any dispatch. Acyclic graph; stable step IDs derive from task/workflowHash/nodeId/iteration tuple. No goto, recursion, shell expression, arbitrary HTTP or script node. All writes retain ordinary preview/approval, frozen versions, current grants and unknown-effect reconciliation. Condition cannot access future outputs or affect a completed step; partial result is explicit.

Declarative `panel.v1` control union: column,row,section,text,textInput,numberInput,toggle,select,button,list,table,resourceLink,preview. Max 1000 controls/depth 16; each has stable ID, optional localized label/help, visible predicate, children only for containers. Input binds one declared schema property, button binds declared operationId and typed arguments; list/table≤500 visible rows plus bounded paging. Controls cannot embed HTML/JS/native control type, arbitrary expression, file path, password value or event handler. Secret entry uses host-owned secure input that returns SecretRef only. Accessibility role/name/focus and error presentation are host behavior, never overridden by a package.

Extension point bindings are generated interface records, not guessed dynamic methods. Initial points are command/action with typed capability arguments, context provider with exact ContextRef selector and consent, artifact provider with owned ResourceVersionRef, settings/panel declarations, importer/exporter ProductJob with typed fidelity, and decoder/analysis recipe with the product profile. First-party business operations cannot switch to generic Invoke; the extension-only dynamic doorway immediately validates the declared schema before handing it to an owner adapter.

## 3. Connection and package lifecycle

Connector owner state is configured/awaitingAuthorization/connected/expired/revoked/failed. Local desktop connection secrets use DesktopPlatform security broker; Cloud connection secrets use the C# secret boundary, referenced by ID to the authorized CF tool adapter. No end-user model BYOK is added. OAuth authorization code+PKCE uses exact provider allowlist/state/redirect and one-use callback receipt; personalToken is entered in protected UI and becomes SecretRef, never package/config/history data. Refresh is single-flight, revoked/unknown refresh outcome blocks new calls until reauthorization; disconnection revokes grants and invalidates the secret reference before best-effort provider revocation.

Owner operations are listDefinitions, listConnections, beginConnection, completeConnection, getConnection, revokeConnection and invoke declared capability. Their exact generated fields/bindings live in wire 04; Mobile may view/use admitted existing connections through Task choices but has no advanced MCP/connector authoring screen. Callback is the declared provider HTTP exception, not an unregistered business route. Provider failures never reinterpret effect unknown as safe retry.

Package install states acquired/verified/staged/awaitingConsent/active/disabled/quarantined/removed; immutable version receipts retain inventory/manifest hashes, grants and dependency pins. Update stages beside the old immutable bytes, validates increased permission and compatibility, stops new admission, drains existing pinned work (max 30 seconds before asking to cancel/wait), migrates private state transactionally under its declared compatibility, then activates one version. Running old/new executable versions never coexist. Existing Task/content receipts retain the old package hash. A user may defer activation without disrupting current work. Unknown external effect is reconciled before any retry; reinstall/update cannot reset its command fence.

Revocation denies new broker calls immediately and applies stop-at-safe-point/process termination when grants cannot be reduced safely. It never deletes product-owned output. Uninstall stops/drains first, asks about private data, leaves professional resources. Rollback is allowed only with declared private-schema compatibility; otherwise keep disabled and preserve state for rescue. A revoked version cannot be resurrected by rollback. Content-only immutable skills/templates already pinned by an admitted task remain recorded, but further capability execution still applies current grants/policy.

## 4. Policy body.v1 and first-party keys

PolicyBundle body is canonical JSON `{schemaVersion,version,parentVersion?,issuedAt,expiresAt,rules,experiments,reason}`; schemaVersion=policy.body.v1. Each rule `{ruleId,key,value,scope,target,priority,effectiveAt?,expiresAt?}` has unique ruleId, integer priority 0–1000 and one declared key below. Scope is realm/workspace/user/installation; target is the corresponding stable ID or the typed predicate below, never secret/user content. Max 1000rules,32experiments,1 MiB body. Signature/keyId in outer PolicyBundle sign exact canonical body bytes. Unknown key/version/type, duplicate priority for overlapping same-key/scope or invalid signature rejects the new bundle atomically; keep last valid bounded state. No silent clamp to a more permissive value.

| Key | Owner; type/default; legal scope and bounds |
|---|---|
| cloud.ai.stop / cloud.tools.stop / cloud.upload.stop / cloud.sync.stop | Cloud; optional stop record; absent means no emergency restriction. realm/workspace; record mode BlockNew/DrainExisting/StopAtSafePoint/ReadOnly, reason, effectiveAt, until≤24h, capability allowlist optional. No authority grant. |
| extension.revokedVersions | Platform; set of packageId/version/hash/reason, defaultempty; realm;≤1000 entries, restrictive sticky revocation until a later signed unrevocation under audited authority. |
| client.minimumContracts | Platform; record public/local major + minimum compatible release, realm; requires explicit supported-window/migration proof, never a bare semver string comparison across products. |
| client.minimumApp | Release; per product/platform minimum versionName and Android minimum versionCode, realm;≤32 entries. Read/export/recovery behavior follows compatibility mode; no disablement of local native data export. |
| mobile.cacheBytes | Mobile; uint64 default 134217728,1048576–536870912; realm/user/installation; LRU acknowledged projections only, never draft/outbox. |
| client.pollIntervalMs | Platform; uint32 default 5000,1000–60000; realm/installation; pending approval prioritization may use existing bounded immediate poll. |
| telemetry.traceSamplePpm | Observability; uint32 default 100000,0–1000000; realm; consent gate still applies, no content. |
| telemetry.traceBufferBytes | Observability; uint64 default 8388608,1048576–16777216; installation; overflow counter required, no false all-errors guarantee. |
| ai.maxModelCalls / ai.maxToolCalls / ai.maxParallelTools | AI; uint32 defaults 16/64/4, max 64/256/8; realm/workspace, minimum 1. Applies to new run snapshot, cannot enlarge compiled cap or current consent/budget. |
| ai.maxActiveMilliseconds | AI; uint64 default 900000,max 3600000,min 1000; realm/workspace; absolute run ceiling remains 7 days. |
| search.webEnabled | Search; bool defaultfalse until configured provider/terms/budget readiness, realm/workspace/user; restriction only, cannot bypass explicit query egress consent. |
| ui.density | Platform; enum comfortable/compact, defaultcomfortable; user/installation, experiment allowed. Explicit user setting wins. |
| mobile.homeSummary | Mobile; enum expanded/compact, defaultexpanded; user/installation, experiment allowed. Required attention remains visible in both. |

Commercial tariffs/service grants/prices/model credentials are **not public policy keys**. The internal ConfigurationDocument schema is a closed composition of the already declared commercial tariff/refill/funding, model route, realm provider, storage/backup and policy profiles with explicit schema version/hash and SecretRef only. Activation requires their cross-field/readiness checks, signed approved manifest, distinct operator approval and same version on every serving replica. A missing commercial configuration refuses paid admission; sample prices are never a production fallback. Model route changes do not retroactively reprice admitted requests.

## 5. Deterministic resolution and experiments

First evaluate emergency/revocation/compatibility restrictions, then realm safety, workspace restrictions, applicable user/installation rules, rollout and defaults. All denials intersect. Numeric capacity/time/parallel limits choose the smallest applicable value and compiled hard maximum; cache/presentation defaults use most specific scope then highest priority, explicit user choice wins where permitted. Value cannot enlarge entitlement/grants or loosen OS security. A kill switch is effective server-side immediately; BlockNew refuses new admission and acknowledges immediately, DrainExisting also reports draining until existing work reaches terminal, StopAtSafePoint requests cooperative stop and retains unknown effects, ReadOnly blocks the affected mutation path while preserving permitted reads/local saves. No mode deletes data.

Target predicate union all/any/not/equal/in/versionAtLeast/percent. Fields are realmId/workspaceId/userId/installationId/product/platform/appVersion/contractsMajor; no user content/email/network fingerprint. Depth≤8,nodes≤128, list≤100. percent uses subject declared as user/workspace/installation, salt bound to policy/experiment version and allocation 0–10000. Hash input is UTF8 components `[namespace,salt,realmId,subjectKind,subjectId]`, each prefixed by uint32 big-endian byte length. SHA256 first 8 bytes big-endian modulo 10000; bucket<allocation includes. No language-specific hashCode/Guid layout. User subject produces identical cross-device assignment.

Experiment record `{experimentId,version,hypothesis,subject,eligibility,variants,allocation,startsAt,endsAt,successMetrics,exitCriteria,exclusionGroup?,holdoutBasisPoints}`. Max 4variants, total allocation+holdout≤10000; variant keys can affect only ui.density/mobile.homeSummary. Partition one deterministic bucket into ordered variant ranges (variant ID ordinal) and holdout, leaving remainder baseline. Exclusion group uses a separate group salt and stable experiment ID ordering to assign one eligible experiment, never several; require nonoverlapping allocated group ranges at validation. Session assignment, if used, is limited to these pure presentation keys and never persisted into work. Record assignment once per version/exposure with minimized analytics consent; no content in metrics. End selects the declared winner/default and archives assignment snapshot. No experiment of entitlement, pricing, consent, persistent format or safety.

Bundles expire≤24 hours; poll on foreground and declared interval, restrictive notices via fastest current channel. On loss/invalid signature retain last known restrictions through expiry; sticky revocations and compatibility floors survive until signed removal. After expiry, defaults apply to presentation/performance, while new Cloud effects requiring current policy are refused with policy.stale until refresh. Local native read/save/export remains available under its existing account rules. Reconnection rechecks current owner state before any queued mutation.

Vectors: same length-prefixed subject input yields identical C#/TS/Kotlin bucket; ambiguous concatenations produce different inputs. At allocation 0 none selected;10000 all eligible selected. Lower workspace maxCalls 8 dominates realm 16; a user setting compact overrides a comfortable presentation experiment. Invalid commercial/model credential reference blocks activation, not old-config service; expired bundle cannot admit a paid run using a guessed tariff. Package update with added network grant waits for consent and keeps old running version pinned.

WP03 publishes exact schema/types/vectors; WP09/11 broker/schema mechanisms; WP41 all six contribution paths/catalog and real OS profile; WP44 signed activation/targeting/expiry/experiments with C#/TS/Kotlin agreement. Required checks include malformed archives, permission expansion, revoke during work, private-schema rollback refusal, secret non-disclosure and unknown external result recovery. These specifications do not claim any of that runtime evidence is already complete.

## 6. Private configuration.v1 composition

ConfigurationDocument.canonicalJson is a closed object with schemaVersion=configuration.v1, version, parentVersion, effectiveAt, realmId and the sections below; reject unknown fields. Lists use stable unique IDs, canonical exact integer/decimal strings and at most 256 entries per section. Total 1 MiB; SecretRef is `{provider,key,version}`, all identifiers, never secret material. All sections are present; explicit enabled=false still validates shape and cannot satisfy a required release gate. A referenced immutable profile must have its canonical bytes/hash in the same manifest or a previously verified immutable config artifact, never an arbitrary URL resolved at activation.

All cross-references resolve once; enabled model/offer requires its matching tariff/supplier/entitlement/profile and ready provider. Validation emits field path/reason without secrets and produces an immutable proposal hash. Bootstrap examples use impossible-to-activate sample identifiers and cannot silently become production defaults.
