# Initial Product Behavior Profiles

Authority: [P2-010](../decisions/phase-2-specification-decisions.md#rule-p2-010). This chapter closes the initial observable rules behind existing accepted Notes, Scope and Slate capabilities. [Editing 18](18-editing-and-rich-content.md), [simulator/interchange 23](23-simulator-and-interchange.md), [wire 04](contracts/04-protobuf-wire-registry.md) and their product requirements remain authorities for unchanged rules. These profiles are versioned payload meanings; an internal implementation may differ only when it produces the same specified outcome. These are future test vectors, not tests already executed.

## 1. Notes editing and conflict profile

`notes.edit.v1` uses stable document/block/inline IDs. A text position is `(blockId,inlineId,offsetUtf16,affinity)` pinned to LocalNotesVersion or CloudRev. TextRun offset is in that run; Link/Mention/Footnote/LineBreak is atomic length 1; a preserved legacy InlineMath occupies the same atomic length but is unsupported for V1 authoring. Surrogate pairs cannot be split. Affinity before/after determines insertion at an exact boundary; document order determines range regardless of selection direction. Storage NFC normalization is applied at the existing owner ingress boundary, never by changing a selected offset without returning the mapping.

| Semantic command | Parameters and single-commit behavior |
|---|---|
| InsertText / ReplaceSelection | Selection plus text and explicit inherited marks; insert at collapsed anchor, or remove selected logical span first. Preserve first surviving TextRun ID; allocate caller-proposed IDs for new runs. Merge adjacent equal-mark text runs into the left ID and return old-to-new offsets. |
| DeleteSelection | Preserve document root and at least one empty paragraph. Across blocks, join compatible surviving text boundaries into first surviving block; tables/atomic blocks are removed only when fully selected. Partial atomic selection refuses. |
| SplitBlock | Position, new blockId/new inlineIds. Keep original left block ID, right gets caller IDs; duplicate applicable block formatting, not task-completion state. Heading's new empty successor is paragraph; list item successor stays same list unless user invokes ExitList. |
| MergeBlocks | Adjacent compatible text blocks, expected versions. Left block ID survives; append right inline content with stable IDs and returned position remap. Refuse cross-table/cell/notebook/root merge; never delete unrelated child blocks. |
| Insert/Move/DeleteBlocks | Explicit parentId,beforeSiblingId, ordered block IDs and new typed blocks; reject cycle, unknown parent, illegal child kind, multiple-parent or duplicate IDs before writing. Move preserves IDs; delete records subtree and references for undo/history. No hidden change to owning document. |
| SetMarks / SetBlockKind | Explicit range and allowed mark/kind. Set marks splits boundary runs with returned IDs, atomic nontext content preserves its own type. Unsupported conversion previews content loss and requires explicit acceptance; no source bytes discarded by toggle. |
| ListIndent/Outdent/Exit | Indent under immediately preceding compatible list item, or refuse if absent. Outdent one level after parent, preserving child order. Exit produces paragraph and splits the list around it. Numbering is derived from list start/style, not identity. |
| TableInsert/DeleteRow/Column | Rectangular typed table, max 200rows by 50columns; insert position explicit. Delete cannot remove last row/column except explicit whole-table deletion. Cell IDs survive unaffected operations. Merge/split cells are not implicit in selection; unsupported imported spans produce visible fidelity. |
| Link/Mention/Embed/Footnote | Explicit typed target and label; internal target must be allowed resource/document/block/view kind. External URL allows http/https/mailto under URL policy, no executable URI. Broken target retains label/identity and shows unavailable; it is never silently retargeted by title. |
| Properties and views | Existing notes.scalar.v1 definition/value/filter/sort/page rules apply. Schema update with dependent values/views refuses unless caller supplies the typed migration preview; no text coercion, silent option removal or formula engine. |

Every command specifies exact affected IDs and one expected owner version. Validate complete batch before one journal transaction; if any command fails, none applies. Result includes the new local version, changed IDs and resulting selection; the returned version references committed origin changes. Insertion/paste places the caret after inserted text, deletion at the surviving start, split at the new right-run start; other structural commands preserve the selection on surviving IDs or select the nearest surviving parent. No deleted ID is silently rebound to different content. The owner retains its exact internal operation map for undo; no caller invents a wire mapping schema. Undo stores inverse content and source version for one user gesture; typing coalesces only while document/version/marks/selection continuity match and gap<=1 second. A paste, IME composition, structural command, remote commit or focus change closes that group. Redo branch is invalidated by a new local command.

Remote whole-document commit with no local pending edit replaces the projection and disables now-invalid undo entries with an explanation and retains their original inverse/content for explicit recovery. With pending edits or composition, persist the complete local proposal as a conflict draft; commit active composition into that draft, retain the acknowledged remote revision separately and ask which proposal to apply/merge. There is no promised automatic CRDT/undo rebase. Undo at a mismatching version refuses and retains the draft; it never applies inverse text to unrelated remote content. IME cancellation affects only its uncommitted composition. Crash preserves already-journaled edits; uncommitted IME text is not falsely claimed durable. Cloud conflict resolution creates a new owner revision and keeps losing proposal/history under existing retention.

Vectors: inserting an emoji represented by a surrogate pair adds2UTF16units; offset inside that pair refuses. Split ab/cd retains left ID/text ab, new right cd; undo restores original identity/content. Deleting across two compatible paragraphs concatenates unselected suffix/prefix once. Remote revision arriving during Chinese IME preserves the completed local draft and remote proposal independently. Failed last-column deletion leaves table unchanged. Permission revoke during conflict display hides protected remote body and preserves local draft only in the same-owner recovery partition.

## 2. Scope acquisition, framing and triggers

`scope.acquisition.v1` pins SourceDefinition, actual device/transport identity, clock mapping, channel types/units/scales, framing/decoder config, trigger snapshot and overflow policy in each capture segment. Source kinds are OS serial, USB explicit interface/endpoint, managed TCP client/server, UDP, file/native replay and the existing simulator. No new Pro/Modbus/MQTT source is inferred from references. Received bytes are immutable evidence; interpretation/decoder change starts a new segment/config revision, never rewrites samples silently.

| Profile | Exact interpretation / limits |
|---|---|
| delimitedText | UTF8, configured start/end byte delimiter 1-16 bytes, optional escaped delimiter using configured single escape byte. Start resynchronization discards prefix with a diagnostic count. End delimiter excluded from payload. LF default, CR stripped only when explicit CRLF end. max frame1 MiB; exceeding stops current frame, emits invalid-frame with byte span and resyncs at next declared start/end boundary. |
| csvLine | UTF8 LF/CRLF, delimiter comma/semicolon/tab selected, double-quoted field with doubled-quote escape, no multiline field. Explicit header/no-header and column mapping. Empty numeric/bool invalid, text may be empty. No locale inference; finite invariant decimal/exponent numeric input only. |
| jsonLine | One bounded JSON object per line, exact declared field paths and scalar types; duplicate key/unpaired surrogate/nonfinite values refuse frame. Missing optional channel becomes explicit missing sample, required channel invalidates the frame. No property-name code evaluation. |
| fixedBinary | Frame byte length 1-1 MiB, field offset/width/type and little/big endian explicit. Wire scalarType keys are u8/i8/u16/i16/u32/i32/u64/i64/f32/f64/bool; bool occupies one byte and accepts raw 0/1 only (the descriptive term bool8 is not another accepted key). Scale/offset applies to the derived engineering value, raw preserved. Bounds/overlaps allowed only for explicit bitfield views. |
| canonicalReplay | Existing af-segment.v1 or native capture segment manifest/hash/timebase. Replay preserves original logical times/gaps/origin and does not convert simulator samples to hardware evidence. |

Optional checksum profile none is represented by absent `FrameConfiguration.checksum`, never a synthetic checksum record. Present `ChecksumSpec.algorithm` uses the exact keys `xor8` (one-byte XOR of the covered bytes), `crc16CcittFalse` for CRC16-CCITT-FALSE(polynomial0x1021,init0xffff,refin/refoutfalse,xorout0), or `crc32IsoHdlc` for CRC32-ISO-HDLC(poly0x04c11db7,init/xorout0xffffffff,refin/refouttrue), with exact covered byte range and checksum field endian. ASCII123456789 gives xor8 `0x31`, CRC16 `0x29b1`, CRC32 `0xcbf43926`. Failure records invalid bytes/span, no zero-filled sample. Per-source raw ring<=64 MiB; backpressure only on transports that support it. Frozen overflow choice stop/dropOldest/dropNewest determines exact lost byte/sample interval and gap event; never hides loss. Default stop for archival capture, dropOldest for preview-only rolling buffer. CPU cannot reorder committed source sequence.

Manual trigger occurs at current source watermark. Threshold/edge trigger defines channel, threshold, direction rising/falling/either, hysteresis>=0, holdoff>=0, pre/post windows, single/repeated mode and max occurrences. Rising arms below threshold-hysteresis and fires at first crossing `previous<threshold && current>=threshold`; falling mirrors it. Analog crossing interpolates linearly in source time; digital crossing is at new sample. Equal repeated values do not retrigger. Missing/nonfinite/gap resets armed history and cannot interpolate across gap. Holdoff is measured from occurrence in source ticks; rearm requires leaving the hysteresis band. Pretrigger ring contains only actual available complete samples; missing earlier coverage is reported, never synthesized. Stop after last sample whose timestamp is inside the half-open post-trigger window. Overlapping repeated windows share immutable source segments but have distinct trigger occurrences, not duplicate samples.

Capture states remain Armed to Running, Running/Paused, Stopped then Finalized, with Interrupted preserving last durable boundary. Config/clock/source change starts a new segment and explicit gap; stop flushes complete records, discards incomplete frame with diagnostic, fsync/journal commits the manifest before Finalized. Resume never silently joins a disconnected replacement device. Host clock monotonic observation and source clock uncertainty remain distinct. Replay speed changes presentation, not recorded timestamps or measurement input.

## 3. Scope analysis.v1

Inputs freeze capture/source revision, half-open range, channel list, exact clock alignment, config/profile and origin. Existing measurements.v1 remains unchanged, including finite-value selection, population statistics and gap-safe pulse behavior. New analyses are derived ProductJobs; publish result+configuration+input hashes atomically and preserve old versions. All counts are uint64, scientific values finite binary64 with units; unavailable is a typed reason with no invented zero. Numeric tolerance is `1e-12 + 1e-9*abs(expected)` unless specified below.

| Family | Closed initial rule | Independent vector |
|---|---|---|
| Spectrum | Single uniform-rate finite channel, N power-of-two 32-1048576, complete consecutive grid, no gap/interpolation by default. Optional explicit linear resample uses declared target rate and refuses a source gap wider than 2source periods. Remove mean, apply periodic Hann `w[n]=0.5-0.5*cos(2*pi*n/N)`. DFT X; one-sided amplitude `abs(X)/sum(w)`, doubled except DC/Nyquist. PSD `abs(X)^2/(fs*sum(w*w))`, same doubling, unit-squared/Hz. Return frequency bin k*fs/N, amplitude, PSD, window/rate/N. | Constant after mean removal produces zero spectrum. Unit sine exactly at non-DC/non-Nyquist bin has peak amplitude 1; integrate PSD equals windowed mean-square normalization, not a sum of amplitudes. |
| Correlation | Two aligned uniform finite series, equal window N2-1048576. Pearson r = Σ((x−x̄)(y−ȳ)) / sqrt(Σ(x−x̄)² · Σ(y−ȳ)²); zero variance unavailable. Cross-correlation lags -L..L, L<=min(N-2,10000), pair x[n],y[n+lag], recompute overlap means/denominator at each lag; require>=2pairs. Max tie chooses smaller abs(lag), then negative lag. No gap bridging. | y=x gives Pearson 1, y=-x gives-1; constant input unavailable. y delayed one sample yields best lag+1 for nonperiodic fixture. |
| Threshold violations | Relation gt/ge/lt/le plus threshold and minimumDuration. Contiguous sample intervals satisfying relation; analog boundary linear, digital right-continuous. Gap splits intervals. Duration is exact source ticks; minimum comparison inclusive. | Samples-1,1 at t0,t2 cross zero at t1; gap between them forbids an interval crossing. |
| Event sequence | Pattern 1-32event kind/channel predicates; maximum gap between consecutive matches, maximum total window, allowOverlap bool(defaultfalse). Stable event order timestamp then source ordinal then event ID. Greedy earliest complete match; nonoverlap resumes after its last event, overlap resumes after first. No backtracking into a prior gap unless the pattern explicitly includes gap. | A@0,B@2,A@3,B@4 with A-to-B maxgap 3 gives two nonoverlap matches; repeated B does not duplicate the same completed match. |
| Protocol summary | Decode UART/I2C/SPI profiles below into immutable frames; count valid/error/parity/framing/address/timeout categories, observed byte throughput and time range. No interpretation of payload as authoritative instrument metadata. | Same decoded frame list always yields same counts; truncated final frame is error/incomplete, never valid zero byte. |

Digital decoder input is time-aligned finite bool channels with source tick positions; reject sample rate insufficient for configured timing before decoding. UART specifies RX, baud, data bits 5-9, parity none/odd/even, stop 1/2, idleHigh(defaulttrue); detect start edge, sample bit centers, no auto-baud, stop/parity errors preserve raw bits. I2C specifies SCL/SDA, sample on rising SCL, start/stop SDA changes while SCL high,7/10 bit address, ACK bit explicit, repeated-start creates linked frame, clock stretching allowed with configured timeout. SPI specifies SCLK/MOSI/optionalMISO/CS, mode 0-3(CPOL/CPHA), bits 4-32, MSB/LSB first, CS polarity and optional fixed-word framing; simultaneous edges follow source ordinal, unknown edge alignment marks ambiguous frame. Decoder config fixes minimum samples per shortest bit interval>=4 and explicit timeout in source ticks. Initial selected defaults UART1152008N1, I2C7 bit, SPI mode 0/8 bit/MSB/active-low; decoder is opt-in and never changes capture bytes. These are independent first-party profiles, no reference implementation reuse.

## 4. Slate edit and keyframe semantics

All positions remain int64 ticks at 705600000Hz. Existing half-open ownership, sourcePTS, output-grid, OTIO and subtitle rules remain. `slate.edit.v1` is a typed batch of semantic commands; expectedNative pins the whole project/sequence. Before mutation expand link/group scope and compute affected tracks/clips/markers/transitions, validate locks/source handles/overlaps/bounds, then commit one undoable transaction. Failure changes nothing. Caller supplies IDs for newly created objects; replay uses identical IDs. Edits preserve affected clip IDs except a split's new right part. No interpolation or snapping changes a stored position without an explicit edit.

| Command | Exact behavior |
|---|---|
| Insert | Place selected source range at point on explicit target track; split an intersected clip at that point and shift the suffix on explicitly selected ripple tracks by inserted duration. Auto-ripple track selection defaults to the target plus expanded linked tracks; UI previews that set. Locked affected track refuses. |
| Overwrite | Replace only the explicit target track interval; trim/split existing intersecting clips, preserve outside ranges and their left IDs/new right IDs. No timeline shift. Explicit linked expansion requires corresponding selected linked tracks, otherwise refuse until user unlinks. |
| Move | Remove selected placements and place at explicit destinations preserving durations/source ranges; destination collision refuses unless caller selects separate overwrite/insert mode. Move group/link together by default; no silent overwrite. |
| Trim in/out | Move boundary within source handles; other boundary fixed. In-trim adjusts source anchor consistently with retime. Positive duration required. Ordinary trim never shifts neighbors and collision refuses. |
| Ripple trim | Trim one boundary, shift subsequent placements and sequence markers on the explicit ripple track set by duration delta. Items before boundary stay; intersected unselected item or locked linked participant refuses. |
| Roll | Two adjacent clips on same track: move shared cut, adjust corresponding source ranges, combined start/end fixed. Both source handles must suffice. Associated transition updates its cut and remains within handles or command refuses. |
| Slip | Change source in/out by same source-time delta, timeline placement/duration fixed; no implicit source extension. |
| Slide | Move middle clip by delta with same source range/duration; trim preceding out and following in so outer combined boundary stays. Requires both neighbors and valid handles; otherwise refuse. |
| Split/razor | Strictly interior point, left ID survives, right ID caller-provided; split linked clips at the same canonical tick projected under existing grid rules. Transfer markers by half-open ownership; effect/keyframe scopes remain original source/local mapping with explicit offsets. |
| Delete / lift | Remove selected clips/range on selected tracks, leave a gap, no timeline shift. Shared group/link references to removed objects are deleted, surviving objects keep IDs. |
| Ripple delete / extract | Remove explicit interval and shift subsequent selected tracks by its duration; split boundary clips first. Removing disjoint selections is processed from latest interval backward, with merged overlapping intervals, so shift occurs once. |
| Duplicate | Deep-copy selected placements with new clip/effect/keyframe/marker/group IDs and same immutable asset references at explicit destinations; collision policy as Move. No duplicate physical media. |
| Group/ungroup / link/unlink | Membership references distinct stable objects. Group controls selection; link controls coordinated AV edit. Remove only requested relationship; cannot change underlying media identity. One object cannot belong to multiple selection groups; linking compatible sourceAV members does not create shared identity. |
| Enable/disable / reorder tracks | Toggle contributes no samples/pixels when disabled, preserves content and graph. Track reordering changes compositing order only; explicit new ordered list contains every track once, role remains unchanged. |
| Transition | Explicit adjacent pair/kind/in-offset/out-offset; handles and typed ports validated. Deleting either side deletes relationship in same transaction. No automatic transition from overlap. |
| Snap | Candidate targets: playhead, clip edges, markers, sequence start, explicit grid. Convert pointer tolerance to ticks once; nearest distance wins, tie priority playhead then marker then clip then grid then earlier tick/ID. Snapping is previewed; final command carries chosen tick, never screen coordinates. |

Ripple markers: sequence markers shift only when their anchor>=edited interval end and included in explicit ripple scope; clip-attached markers move with their clip/source-local interpretation. Anchors inside a deleted interval are included in deletion preview and either removed or moved to interval start by the caller's explicit marker policy (defaultremove). Locked tracks cannot be silently excluded from a linked/group operation.

RetimeCurve is the exact ordered list of (timelineOffset,sourceOffset) points in wire 04. Offsets are canonical ticks; first timelineOffset=0, last=clip duration, with at least 2points and strictly increasing timeline offsets. The exact rational slope between source offsets selects forward/reverse speed; zero is hold. Source mapping is piecewise linear with checked arbitrary-width intermediates; evaluate from the segment anchor rather than accumulating delta. Adjacent segments share their endpoint; a discontinuity requires an explicit clip split/edit, not an unrepresented hidden cut. Source video chooses the enclosing half-open original PTS interval; audio uses the pinned resampler at the exact mapped source phase. Canonical endpoint conversion uses ties-to-even once; no intermediate float/tick truncation. Preflight complete source/filter handles, preserve original timestamps, and refuse unavailable required ranges. Default speed change changes audio pitch; pitch-preserving stretch is not silently assumed.

Keyframes are hold (right-continuous step), linear or bezier; times unique and strictly increasing in the declared clipLocal/sequence scope (track effects use sequence time). Step is right-continuous; linear interpolates normalized parameter value between surrounding tick positions; outside range clamp nearest endpoint. Bezier uses the existing explicit tangent contract: cubic Hermite between endpoints, h00=2u³-3u²+1, h10=u³-2u²+u, h01=-2u³+3u², h11=u³-u²; multiply each value-per-second tangent by exact segment seconds before evaluation. Missing tangent is zero; no automatic easing/tangent inference. Overshoot remains until the parameter definition explicitly clamps its admissible range. Move/ripple changes placement but never keyframe scope; trim retains out-of-range keyframes for undo/re-extension and excludes them from evaluated interval. Example values 0@tick 0,1@tick 10: linear at 5=.5, step at 5=0, both at 10=1.

## 5. Slate processing, colour, audio and derived analysis

CPU baseline is scene-linear Rec709 primaries/D65, premultiplied RGBA float32. OCIO config/input/working/display/view/output and asset hashes are pinned in project/render profile. Decode matrix/range is applied before transfer conversion; input metadata missing prompts the explicit default interpretation Rec709/sRGB with warning, never mutates source metadata. Working RGB may be negative or above 1; no early clipping. Export/display clamps only at the declared target integer conversion. Alpha in[0,1], alpha 0 RGB 0.

Effect order is the stored graph order. Exposure `rgb*=2^stops`; contrast `rgb=(rgb-0.18)*contrast+0.18`; saturation `rgb=L+(rgb-L)*s`, `L=.2126R+.7152G+.0722B`, all on straight RGB then premultiply, alpha unchanged. Opacity multiplies premultiplied RGB and alpha. Source-over composite `C=Cs+Cd*(1-As)`, `A=As+Ad*(1-As)`. Crop removes outside normalized margins; transform uses center pivot and inverse mapping with declared bilinear/lanczos sampling, outside transparent. Identity operation is exact except float roundoff. Picture dissolve uses existing linear weights. Tolerance baseline absolute1e-5 per float channel before output quantization;8 bit comparisons permit1LSB and report colorspace/profile.

Audio float32 interleaved, explicit mono/stereo mapping, gain 10^(dB/20), equal-power pan/crossfade as already specified. Mix sums contributions once per output sample under [BO-02](23-simulator-and-interchange.md#rule-bo-02); master integer output clamps[-1,1) only at quantization, no hidden limiter/normalizer. No random dither in baseline deterministic mode. Audio resampling uses the pinned native profile with delay/drain; exported sample count follows canonical range, not buffer sizes. Loudness follows [ITU-R BS.1770-5](https://www.itu.int/rec/R-REC-BS.1770-5-202311-I/en) integrated loudness with K-weighting/channel weights/absolute-70LUFS and relative-10LU gating,400ms blocks 75%overlap; silent/too-short data unavailable. True peak uses 4x oversampling and records method, tolerance 0.2dB; loudness tolerance 0.1LU against reference vectors. Gain application is a separate explicit edit, not part of measurement.

Derived scene detection profile: decode selected original at each source presentation frame, resize32x32 luma, mean absolute normalized difference from previous valid frame; threshold default.25 range 0-1, minimum scene length 1 frame. A cut appears at current frame PTS when difference>=threshold and minimum length holds; gap starts unknown coverage, not a detected content cut. Motion profile: same32x32 frames, integer translations dx/dy in[-4,4], minimize mean absolute luma difference on shared interior, tie smallest squared distance then dy then dx. Return displacement per source frame/time and residual; it is derived visual motion, not calibrated physical motion. All-solid identical frames: no cuts, motion(0,0); black to white: one cut at boundary with difference 1. Record algorithm/version/input hashes and no AI/hardware provenance claim.

Baseline generated sources and title/subtitle font/origin rules remain in 23. Native output profiles remain MatroskaFFV1+PCMs24le, WAVPCMs24le and MP4MPEG4Part2+AAC. User-visible codecs are named honestly. The graph's CPU definition is the oracle for optional GPU optimization; preview frame dropping changes presentation quality only. Render pins original/proxy choice, graph/time/colour/font/library hashes, writes staged output+sidecars, validates then commits atomically. Cancellation exposes completed verified outputs individually in a batch; an unfinished single output is not a complete artifact. Restart re-runs only uncommitted deterministic ProductJob stages under the same snapshot; a changed input starts a new job after review.

## 6. Wire and implementation binding

The exact edit/analysis options above are closed generated records in wire 04, not dictionaries. Notes commands and Slate semantic edits are validated by the owner before lowering to journal changes. Scope frame/trigger/decoder/analysis configuration is frozen in capture/analysis records. First-party capability binding resolves to existing local Notes/Scope/Slate operation services and their input/output schema IDs; a consumer cannot submit arbitrary method names, SQL, scripts or host paths.

WP18/19/28 implement Notes vectors and conflict preservation; WP33/34/35 implement acquisition/analysis/report fidelity; WP36/37/38/39 implement every [TL-06](../requirements/products/arcslate.md#rule-tl-06) command, graph/colour/audio/output/OTIO vector; WP51 shares the existing simulator transport/measurement fixtures. WP03 generates full schema/type fixtures first, WP13 the native primitives. Final acceptance uses actual owner stores, packages and failure injection; mathematical examples here do not claim runtime verification.

## Initial math profile — notes.math.v1

Stored source is unchanged UTF-8 TeX, display block only. Supported grammar: numeric/Latin/Greek identifiers, whitespace, grouping `{}`, unary/binary +−×÷=<>≤≥, superscript/subscript, fractions, square/nth roots, sums/products/integrals with limits, standard trig/log/exp operators, scalable parentheses/brackets and matrices with rows/cells. No custom macros, filesystem/network commands, packages, scripts, HTML, arbitrary fonts or inline math atom. Source must satisfy both the wire limit of 4096 Unicode scalars and 16 KiB UTF-8, with maximum depth 32, matrix 32×32 and 10,000 layout nodes; exceeding a bound or encountering an unsupported command shows preserved source with a visible unsupported marker. Never silently omit a token or execute TeX. Avalonia renders a bounded native layout with accessible source/copy; export preserves source and reports unsupported rendering. WP18 vectors cover nested fractions, RTL surroundings, bounds and unsupported commands. The accepted profile may be extended only through a versioned compatibility change.
