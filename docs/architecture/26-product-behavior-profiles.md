# Initial Product Behavior Profiles

Authority: [P2-010](../decisions/phase-2-specification-decisions.md#rule-p2-010). This chapter closes the initial observable rules behind existing accepted Scope capabilities. [Editing 18](18-editing-and-rich-content.md), [simulator 23](23-simulator-and-interchange.md), [wire 04](contracts/04-protobuf-wire-registry.md) and their product requirements remain authorities for unchanged rules. These profiles are versioned payload meanings; an internal implementation may differ only when it produces the same specified outcome. These are future test vectors, not tests already executed.

## 1. Scope acquisition, framing and triggers

`scope.acquisition.v1` pins SourceDefinition, actual device/transport identity, clock mapping, channel types/units/scales, framing/decoder config, trigger snapshot and overflow policy in each capture segment. Source kinds are OS serial, USB explicit interface/endpoint, managed TCP client/server, UDP, file/native replay and the existing simulator. No new Pro/Modbus/MQTT source is inferred from references. Received bytes are immutable evidence; interpretation/decoder change starts a new segment/config revision, never rewrites samples silently.

| Profile | Exact interpretation / limits |
|---|---|
| delimitedText | UTF8, configured start/end byte delimiter 1-16 bytes, optional escaped delimiter using configured single escape byte. Start resynchronization discards prefix with a diagnostic count. End delimiter excluded from payload. LF default, CR stripped only when explicit CRLF end. max frame1 MiB; exceeding stops current frame, emits invalid-frame with byte span and resyncs at next declared start/end boundary. |
| csvLine | UTF8 LF/CRLF, delimiter comma/semicolon/tab selected, double-quoted field with doubled-quote escape, no multiline field. Explicit header/no-header and column mapping. Empty numeric/bool invalid, text may be empty. No locale inference; finite invariant decimal/exponent numeric input only. |
| jsonLine | One bounded JSON object per line, exact declared field paths and scalar types; duplicate key/unpaired surrogate/nonfinite values refuse frame. Missing optional channel becomes explicit missing sample, required channel invalidates the frame. No property-name code evaluation. |
| fixedBinary | Frame byte length 1-1 MiB, field offset/width/type and little/big endian explicit. Wire scalarType keys are u8/i8/u16/i16/u32/i32/u64/i64/f32/f64/bool; bool occupies one byte and accepts raw 0/1 only (the descriptive term bool8 is not another accepted key). Scale/offset applies to the derived engineering value, raw preserved. Bounds/overlaps allowed only for explicit bitfield views. |
| canonicalReplay | Existing af-segment.v1 or native capture segment manifest/hash/timebase. Replay preserves original logical times/gaps/origin and does not convert simulator samples to hardware evidence. |

Optional checksum profile none is represented by absent `FrameConfiguration.checksum`, never a synthetic checksum record. Present `ChecksumSpec.algorithm` uses the exact keys `xor8` (one-byte XOR of the covered bytes), `crc16CcittFalse` for CRC16-CCITT-FALSE(polynomial0x1021,init0xffff,refin/refoutfalse,xorout0), or `crc32IsoHdlc` for CRC32-ISO-HDLC(poly0x04c11db7,init/xorout0xffffffff,refin/refouttrue), with exact covered byte range and checksum field endian. ASCII123456789 gives xor8 `0x31`, CRC16 `0x29b1`, CRC32 `0xcbf43926`. Failure records invalid bytes/span, no zero-filled sample. Per-source raw ring<=64 MiB; backpressure only on transports that support it. Frozen overflow choice stop/dropOldest/dropNewest determines exact lost byte/sample interval and gap event; never hides loss. Default stop for archival capture, dropOldest for preview-only rolling buffer. CPU cannot reorder committed source sequence.

Manual trigger occurs at current source watermark. Threshold/edge trigger defines channel, threshold, direction rising/falling/either, hysteresis>=0, holdoff>=0, pre/post windows, single/repeated mode and max occurrences. Rising arms below threshold-hysteresis and fires at first crossing `previous<threshold && current>=threshold`; falling mirrors it. Analog crossing interpolates linearly in source time; digital crossing is at new sample. Equal repeated values do not retrigger. Missing/nonfinite/gap resets armed history and cannot interpolate across gap. Holdoff is measured from occurrence in source ticks; rearm requires leaving the hysteresis band. Pretrigger ring contains only actual available complete samples; missing earlier coverage is reported, never synthesized. Stop after last sample whose timestamp is inside the half-open post-trigger window. Overlapping repeated windows share immutable source segments but have distinct trigger occurrences, not duplicate samples.

Capture states remain Armed to Running, Running/Paused, Stopped then Finalized, with Interrupted preserving last durable boundary. Config/clock/source change starts a new segment and explicit gap; stop flushes complete records, discards incomplete frame with diagnostic, fsync/journal commits the manifest before Finalized. Resume never silently joins a disconnected replacement device. Host clock monotonic observation and source clock uncertainty remain distinct. Replay speed changes presentation, not recorded timestamps or measurement input.

## 2. Scope analysis.v1

Inputs freeze capture/source revision, half-open range, channel list, exact clock alignment, config/profile and origin. Existing measurements.v1 remains unchanged, including finite-value selection, population statistics and gap-safe pulse behavior. New analyses are derived ProductJobs; publish result+configuration+input hashes atomically and preserve old versions. All counts are uint64, scientific values finite binary64 with units; unavailable is a typed reason with no invented zero. Numeric tolerance is `1e-12 + 1e-9*abs(expected)` unless specified below.

| Family | Closed initial rule | Independent vector |
|---|---|---|
| Spectrum | Single uniform-rate finite channel, N power-of-two 32-1048576, complete consecutive grid, no gap/interpolation by default. Optional explicit linear resample uses declared target rate and refuses a source gap wider than 2source periods. Remove mean, apply periodic Hann `w[n]=0.5-0.5*cos(2*pi*n/N)`. DFT X; one-sided amplitude `abs(X)/sum(w)`, doubled except DC/Nyquist. PSD `abs(X)^2/(fs*sum(w*w))`, same doubling, unit-squared/Hz. Return frequency bin k*fs/N, amplitude, PSD, window/rate/N. | Constant after mean removal produces zero spectrum. Unit sine exactly at non-DC/non-Nyquist bin has peak amplitude 1; integrate PSD equals windowed mean-square normalization, not a sum of amplitudes. |
| Correlation | Two aligned uniform finite series, equal window N2-1048576. Pearson r = Σ((x−x̄)(y−ȳ)) / sqrt(Σ(x−x̄)² · Σ(y−ȳ)²); zero variance unavailable. Cross-correlation lags -L..L, L<=min(N-2,10000), pair x[n],y[n+lag], recompute overlap means/denominator at each lag; require>=2pairs. Max tie chooses smaller abs(lag), then negative lag. No gap bridging. | y=x gives Pearson 1, y=-x gives-1; constant input unavailable. y delayed one sample yields best lag+1 for nonperiodic fixture. |
| Threshold violations | Relation gt/ge/lt/le plus threshold and minimumDuration. Contiguous sample intervals satisfying relation; analog boundary linear, digital right-continuous. Gap splits intervals. Duration is exact source ticks; minimum comparison inclusive. | Samples-1,1 at t0,t2 cross zero at t1; gap between them forbids an interval crossing. |
| Event sequence | Pattern 1-32event kind/channel predicates; maximum gap between consecutive matches, maximum total window, allowOverlap bool(defaultfalse). Stable event order timestamp then source ordinal then event ID. Greedy earliest complete match; nonoverlap resumes after its last event, overlap resumes after first. No backtracking into a prior gap unless the pattern explicitly includes gap. | A@0,B@2,A@3,B@4 with A-to-B maxgap 3 gives two nonoverlap matches; repeated B does not duplicate the same completed match. |
| Protocol summary | Decode UART/I2C/SPI profiles below into immutable frames; count valid/error/parity/framing/address/timeout categories, observed byte throughput and time range. No interpretation of payload as authoritative instrument metadata. | Same decoded frame list always yields same counts; truncated final frame is error/incomplete, never valid zero byte. |

Digital decoder input is time-aligned finite bool channels with source tick positions; reject sample rate insufficient for configured timing before decoding. UART specifies RX, baud, data bits 5-9, parity none/odd/even, stop 1/2, idleHigh(defaulttrue); detect start edge, sample bit centers, no auto-baud, stop/parity errors preserve raw bits. I2C specifies SCL/SDA, sample on rising SCL, start/stop SDA changes while SCL high,7/10 bit address, ACK bit explicit, repeated-start creates linked frame, clock stretching allowed with configured timeout. SPI specifies SCLK/MOSI/optionalMISO/CS, mode 0-3(CPOL/CPHA), bits 4-32, MSB/LSB first, CS polarity and optional fixed-word framing; simultaneous edges follow source ordinal, unknown edge alignment marks ambiguous frame. Decoder config fixes minimum samples per shortest bit interval>=4 and explicit timeout in source ticks. Initial selected defaults UART1152008N1, I2C7 bit, SPI mode 0/8 bit/MSB/active-low; decoder is opt-in and never changes capture bytes. These are independent first-party profiles, no reference implementation reuse.

## 3. Wire and implementation binding

The exact edit/analysis options above are closed generated records in wire 04, not dictionaries. Scope frame/trigger/decoder/analysis configuration is frozen in capture/analysis records. First-party capability binding resolves to the existing local Scope operation service and its input/output schema IDs; a consumer cannot submit arbitrary method names, SQL, scripts or host paths.

WP33/34/35 implement acquisition/analysis/report fidelity; WP51 shares the existing simulator transport/measurement fixtures. WP03 generates full schema/type fixtures first, WP13 the native primitives. Final acceptance uses actual owner stores, packages and failure injection; mathematical examples here do not claim runtime verification.
