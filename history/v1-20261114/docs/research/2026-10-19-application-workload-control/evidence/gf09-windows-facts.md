# Windows facts settled across tracks: evidence record

- **Scope:** research evidence of the 2026-10-19 vision-correction study (application and workload control); not verification-register facts. Evidence labels are defined in this folder's [README](../README.md).
- **Date:** 2026-10-19.
- **Source:** the study's Windows fact-settlement gap-fill (report 37), which settled facts on which the Windows tracks disagreed, including its independent challenge log, and the study's digest of it. Claims appear in their challenged form; the corrections made after the digest are listed in "Review corrections". Values are pre-lab, never realized guarantees.
- **Publication:** curated for the public ArcForges-Design repository. No row describes a particular host.
- **Columns:** **ID** `D2-gf09-windows-facts-<n>` is stable; numbers are not reassigned, so a fact that is not published leaves a gap. **Claim** states the fact; the text after "For ArcForges:" is the study's roadmap-level consequence, never a decision. **Evidence** gives the label(s), then the integration levels, whether the application must cooperate, and the platform. **Report section** is provenance only (the section of report 37 the digest cites).
- **Not published:** D2-gf09-windows-facts-9 (clipboard-isolation remedies: separate window stations and desktops) and -13 (a clipboard basis-fact proposal, superseded by chapter 17's fixed read sentence). Clipboard isolation is outside the study's scope (the scope correction of 2026-10-19); the facts that support the clipboard's disclosure as a named gap are kept.
- **Reading notes:**
  - Integration levels: L1 observe; L2 apply resource controls to a running process; L3 launch and supervise; L4 launch with an OS-enforced access sandbox; L5 voluntary SDK or local API.
  - W2 is an AppContainer, W3 an LPAC; *hand-built* is a launcher-made AppContainer token without package identity; *appSilo* is a Win32 app isolation package.
  - **pointer** and **vendor-tracker** (a Microsoft contributor on the project's issue tracker) rank below E3. E1-DP is DesktopPlatform code.
  - (A) means the process-level dimensions; (B) the GUI interaction channels, which this study does not isolate.
  - `LAB2-…` IDs name entries of [lab-register.md](../lab-register.md). `D-…` facts and `LAB-…` entries are the [2026-10-18 record](../../2026-10-18-delegated-execution/README.md)'s; G-numbered gates are the two registers' gates. DX-ACC rules are defined in D2-gf05-access-denial-33.
  - The AppContainer stays the single Microsoft-serviced Windows (A) boundary; GUI applications stay first-class W2/W3 candidates.
